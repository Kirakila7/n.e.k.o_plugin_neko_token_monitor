# 猫粮 · YUI 桌面陪伴与额度挂件

## 0.8.27 · 2026-10-19

气泡只保留数值和「平台名＋额度剩余 / 账户余额」，移除自动、桥接、未设置总额等小字。详细来源和查询状态可在设置中查看。

新增默认自动跟随 macOS 前台应用或浏览器页面，也可以始终监测指定平台。右键猫粮气泡选择「自动跟随前台应用 / 页面」或「固定当前猫粮」；在猫粮设置顶部可以指定固定的平台，偏好在重启后保留。打开猫粮自身设置或 NEKO 窗口时保持上一个平台。

自动识别平台后沿用各平台原有的查询来源；尚未接入的来源会提示配置。DeepSeek 开放平台在未配置 API Key 时，可读取当前前台用量页的充值余额与赠送余额合计，按页面精度显示；切离余额页后标为上次读数。已配置 API Key 时继续使用该密钥对应账户，避免混用网页登录账户。ChatGPT／Claude 等手动额度仍需手动记录，不因识别了页面就获得实时余额。浏览器只提取官方域名与已适配余额字段，不读取对话或输入框。

改进人物移位后的接管定位、退出恢复，以及 TRAE 打开 / 切回自动读取和充值直达。自动前台识别与网页金额读取本轮仅在 macOS 正式 NEKO 中验证；接管仍有间歇失败，不能视作所有位置与宿主均已解决。实测范围见[更新日志](CHANGELOG.md)。

## 0.8.26 · 2026-10-18

本版修复新安装后辅助程序无法执行、挂件页面崩溃后原版未恢复、断网退出未结束记录、首次自动启动丢失接管确认四个问题。退出请求和原生结束标记会持久保存；恢复连接或重开时补发，旧点击不会重复计数，旧会话结束请求不会影响新会话。快速重开时取消之前的关闭计时。

本机连续三轮、12个原生隔离场景及三轮页面交互通过，另有69项Python回归和8组JS检查。原生回归使用独立Cocoa宿主与真实AppKit/WebKit，验证窗口恢复和记录落盘；原版Live2D暂停及辅助功能权限使用测试替身，不将结果扩展为所有正式NEKO宿主通过。详见[更新日志](CHANGELOG.md)。

右键 **猫粮气泡** 设置平台、额度、Token 与「补充猫粮」入口；右键 **YUI 图片** 管理互动记录显示、回忆、记忆重试、跳动与追逐，以及「和猫娘一起玩」退出模式。点气泡切换余额与 Agent 空闲时间，点人物保留摸头与带喵反馈。可在 N.E.K.O. 对话中输入「查看猫粮监测功能」打开，或输入「帮我看看猫粮还剩多少」仅查询；需要当前模型支持并启用工具调用。

### 现有功能

- 额度剩余不超过 75%、50%、25% 时脸部逐档变暗；只有 **低于 50%** 才左右跳动，**低于 10%** 触发小白猫追逐大肥鱼。没有可用总量时不猜剩余百分比，金额、预算、订阅额度和上下文 Token 分开说明。
- 小白猫使用 N.E.K.O. 原127帧素材。大肥鱼正常奔跑、受惊与生气采用 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 的素材；2/4/6/8 次追到逐渐变黑，10 次后换成此前的戴头套大肥鱼反追 YUI。保留这版人物和头套造型。
- Q版 YUI 跑路增加到12帧；被追到时切换为 **闭眼缩身、蹲下、晕乎乎、恢复平衡** 四帧动作，约1.15秒恢复跑步。可见回弹、短暂绕星和「呜喵！轻、轻一点喵～」文字气泡；受击中也能拖回原站位恢复精神。
- macOS 小猫与大肥鱼统一在 WebKit 动画层逐帧绘制，透明原生窗口只接收拖动；减少原来约20 Hz位置更新带来的顿挫。退出、恢复或拖回时清理特效，追到计数留在记录中。
- 增加 DeepSeek Harness 余额桥接及应用内充值入口，完善 Codex、TRAE、WorkBuddy、DeepSeek、Kimi、Qwen 等档案与官方补充入口。不同平台和币种独立，不将手动积分或自定预算写成官方实时余额。

### 平台额度与补充入口

| 平台 | 额度来源 | 补充猫粮 |
| --- | --- | --- |
| DeepSeek Harness | 登录账户的本机只读桥接；需先安装本包 `integrations/deepseek-harness` | Harness 原生充值视图优先，官网备用 |
| Codex | 本机官方 app-server 的套餐额度窗口 | 官方用量页 |
| TRAE 中国版 | macOS打开 / 切回应用自动读取积分并返回任务；可用手动记录 | 应用内增购优先，官网备用 |
| WorkBuddy | macOS面板适配或手动记录；真实客户端尚未实测 | 官网优先；客户端导航仍待实机验收 |
| DeepSeek / Kimi API | 对应官方余额接口；Kimi区域独立 | 对应官方控制台 |
| Qwen / 阿里云 | 官方云账户查询或手动额度；共享余额并非单模型额度 | 先选择云账户或聊天产品 |
| GPT / Claude API | 用户预算减组织费用，属于估算 | 对应官方费用或账户页面 |
| 其他平台 / JEV | 手动额度、自定义HTTPS余额，或本机用量上报 | 已核验的官方入口，未知平台不推测地址 |

**接管与平台范围：**独立插件通过暂停并隐藏原版窗口来接管，退出时恢复，不卸载 Live2D。macOS接管需要辅助功能权限。0.8.25新增追逐、受击与额度适配在macOS独立挂件及隔离页面验证；不将这些结果称为所有正式宿主版本通过。Windows保留原生窗口程序，但本次未完成Windows桌面、语音和记忆实机回归；TRAE/WorkBuddy面板读取与应用内导航目前仅macOS。语音与长期记忆依赖实际NEKO服务，排队或收到请求不表示已出声或写入成功。

**使用素材：**dsh-pet素材允许开源使用、禁止商用，介绍、展示和分发须附上 [原作者仓库](https://github.com/PC2005-cloud/dsh-pet)。代码的Apache-2.0许可不替代素材条件。详见 [素材声明](DSH-PET-ASSET-NOTICE) 和 [素材清单](ARTWORK.md)。本项目是社区作品，不表示NEKO、DeepSeek或素材作者背书。

## 0.8.4 本机试听版：节奏演奏器

右键 YUI →「节奏演奏器」。开启后直接按节奏点 YUI，内置旋律逐音向前走；不需要选琴键，点击间隔就是演奏节奏，并保留摸头计数。小控制条提供试听、停止与设置；音高、音量和循环试听放在设置里，音高与音量会在本机记住。演奏期间暂不请求原版语音，关闭后恢复普通互动。退出记录模式、关闭演奏器或页面隐藏时立即停止。默认不自动播放。

内置节奏来自用户提供的按压视频，保留约 11 秒音乐段的起音时序，省略末尾平台提示。音色为用户提供的鲸鱼插件视频中 0.2 秒短采样；音高由频谱估计，属于近似复现，尚未完成逐音听感验收。0.8.8 包含这一短采样与节奏数据。

## 查询方式

界面始终叫「猫粮余额」，下方明确显示数据来源。

| 方式 | 含义 | 所需设置 |
| --- | --- | --- |
| Codex 当前登录账号 | 套餐剩余百分比与重置时间 | 本机安装并登录 Codex CLI / app-server |
| DeepSeek | 官方账户余额 | API Key |
| OpenAI / GPT | 自定预算减组织已用费用，非平台余额 | Admin API Key、USD 预算与起始日期 |
| Anthropic / Claude | 自定预算减组织已用费用，非平台余额；不含 Priority Tier | 有组织费用查询权限的密钥、USD 预算与起始日期 |
| 自定义服务商 | 用户指定 HTTPS GET 接口返回的余额 | 地址、Bearer 密钥、JSON 金额字段路径 |
| JEV | 本机桥接上报的输入/输出 token；无账户余额 | 连接本机 JEV 用量上报桥接 |
| 任意模型 | 手动预算，不自动扣减 | 金额、币种、模型备注 |

模型名称仅作备注；组织费用包含全部模型，不能当作单模型用量。ChatGPT/Claude 订阅额度、API 账户余额和上下文剩余量不是同一项。可用 token 仅按用户填写的综合单价估算，不代表平台承诺。

## v0.7.2 新功能

现在可在查询方式中选择 Codex 当前账号额度或 JEV 本机请求用量。Codex 默认每 5 分钟自动查询，无需在插件填写密钥；JEV 需要本机桥接主动上报，不会自动捕获任意客户端流量。详情见 [更新日志](CHANGELOG.md)。

### JEV 桥接协议

本机客户端先 GET `http://127.0.0.1:48923/api/status` 取得 `csrf`，随后使用 `X-Neko-CSRF` 请求头向 `/api/usage` POST JSON：`{"provider":"jev","request_id":"每次真实请求的唯一ID","model":"jev-latest","input_tokens":100,"output_tokens":20}`。示例数值不是实际用量。仅对成功、未缓存的真实调用上报；不要发送密钥、提示词或回答。插件离线时本版本不自动回补。

## 互动与记录

- 点人物：弹跳、显示带「喵～」的台词，并请求 NEKO 原角色回应。是否出声取决于原软件语音设置；回应请求有 30 秒冷却。
- 点气泡：切换余额与 Agent 空闲/忙碌状态。
- macOS 记录模式先通过原版「请她离开」暂停模型，再隐藏原界面；退出后通过「请她回来」恢复本插件主动暂停的模型。Windows 仍为窗口隐藏／恢复。退出后显示摸头、询问计数。
- 摸头指点击人物；询问指点击气泡。退出时通过 NEKO 记忆导入 API 写入 **YUI** 的事实记忆。失败保留本机记录，可重试。
- 菜单首项「和猫娘一起玩」退出记录模式；退出后显示「开始记录模式」。菜单可重试记忆保存，拖动人物可移动窗口。

## 安装与平台

在 NEKO 插件中心导入 Release 中的 `neko_token_monitor.neko-plugin`，启动后自动显示。

- macOS 11+：包含 Apple Silicon / Intel 通用窗口程序；需在系统设置允许猫粮使用辅助功能，才能暂停和恢复原版人物。接管失败会退回正常模式；有些原版界面需要先显示人物旁的控制按钮。此前版本验证过实际NEKO进入/退出；本次新增功能的验证范围见上文。
- Windows 10/11 x64：包含 .NET Framework 4.8 / WebView2 窗口程序；需要 Microsoft Edge WebView2 Runtime。构建检查由 Windows runner 执行，桌面透明、恢复和语音效果仍需用户机器验证。
- Linux 暂不提供原生悬浮窗。

目前使用 NEKO 默认本机端口 48911 和猫粮端口 48923；自定义端口环境尚不支持。只适用于本机运行 NEKO。

## 隐私

查询密钥和互动记录保存在 NEKO 分配的插件数据目录，安装包不包含用户配置。macOS 配置文件权限为 0600；Windows 依赖当前用户数据目录权限。切换服务商或自定义地址时不复用旧密钥。网络只用于所选余额/费用接口及本机 NEKO 服务；不发起测试聊天消费。自定义接口不跟随重定向。

## 0.8.0 多模型额度总览

右键气泡 → **模型额度总览**。每个平台独立设置并保存在本机；点击卡片的「设置 / 接入」填写，保存后自动切换展示。已配置来源继续后台查询，点「气泡展示」切换主气泡，不需要重新填写其他来源密钥。旧版本当前来源会自动迁移。

| 类型 | 来源 | 展示内容 |
| --- | --- | --- |
| 自动套餐查询 | Codex | 本机登录账号返回的额度百分比与重置时间 |
| 自动余额查询 | DeepSeek、OpenRouter、硅基流动 | 服务商账户共享余额，非单模型独立额度 |
| API 预算估算 | GPT / OpenAI API、Claude API | 自定预算减组织费用，非官方余额或订阅额度 |
| 手动额度 | ChatGPT、Claude / Claude Code、Gemini、豆包、GLM等 | 手填剩余、总量、单位、重置备注；与支持自动查询的API档案独立 |
| 本机用量 | JEV | 桥接上报累计 token，非剩余额度 |
| 其他 | 自定义 HTTPS 接口、手动金额 | 用户自己的服务商或预算 |

OpenRouter 需要 **Management Key**，普通聊天 Key 可能没有权限。硅基流动使用中国站 API Key，读取 `totalBalance`。密钥只发往固定对应平台。没有凭据时展示未连接，不推测余额；不同平台与不同币种不合并。

官方接口参考：[OpenRouter credits](https://openrouter.ai/docs/api/api-reference/credits/get-remaining-credits)、[硅基流动 OpenAPI](https://github.com/siliconflow/siliconcloud/blob/main/openapi.yaml)、[OpenAI 组织 API](https://developers.openai.com/api/reference/python/resources/admin/subresources/organization)。


## 记录与退出（0.8.2）

人物右键菜单首项「和猫娘一起玩」会恢复原版窗口并显示互动总结；退出后不会因刷新自动再次进入。底部「互动记录」可查看累计次数和最近 100 段历史。每次点击保存在本机，全部会话保留在插件用户数据目录 `recording/recording.json`（另有备份）。YUI 记忆失败会自动重试，界面明确标注待同步，不阻塞下一段记录。旧版已经覆盖的会话无法恢复。

记录模式需要原生挂件成功隐藏 NEKO 窗口，浏览器页面不接管桌面。无法隐藏时自动保留正常模式。升级 0.8.1 后请停用并重新启用插件以加载新的原生程序。


### 额度脸色（0.8.18 本地试用）

YUI 按气泡所选账户的剩余比例变化：高于 75% 保持原表情，剩余不超过 75%、50%、25% 时阴影逐档加深。补充额度后恢复；点击反馈、跟拍和换装继续可用。

- 手动 Token：在「模型额度总览」填写剩余 Token 和同单位的「猫粮总额度／预算」。例如剩余 500,000、总额 1,000,000，气泡显示「50万 token · 剩余 50%」。不会自动扣减手动数值。
- Codex：读取额度窗口，采用剩余百分比最低的一项；不把上下文长度当成套餐额度。
- GPT/Claude API：使用已有费用预算。其他金额来源：可填写同币种的「猫粮参考总额」，例如余额 5 元、参考总额 20 元对应 25%。
- 没有总额度、JEV 仅有本机已用 Token、或尚未连接时，不猜剩余百分比，保持原表情。旧数据继续标为上次数据。
- 金额按自填单价换算的 Token 以「≈」标明估算，无法保证某种模型实际可用的 Token 数。
